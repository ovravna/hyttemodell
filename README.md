# hyttemodell

Interactive purchase model for Kausebøl 19, 1821 Spydeberg (gnr. 418, bnr. 5, fnr. 10).
Trilingual: norsk / english / italiano.

Live: https://ovravna.github.io/hyttemodell/

## Local development

```
npm install
npm run dev
```

## Build

```
npm run build
```

Deploys automatically to GitHub Pages on push to `main`.
